## 覆盖场景

- API：碎片化 SSE、非流式、模型列表、向量索引顺序、鉴权错误脱敏、断流、输出截断、取消。
- 群聊：轮换、点名、后发角色看到先发回复、失败/取消后不调用后续角色。
- 记忆：世界隔离、向量空间匹配、锁定保护、编辑使旧向量失效、非法结构不提交、摘要失败不推进游标、大小摘要/阶段/表格提交。
- 备份：副本 UUID 重映射、世界/房间/记忆关联、跨世界错误引用拒绝、损坏文件拒绝、排除密钥。
- 导入：V1/V2/V3 JSON、PNG tEXt/CRC、直接数组世界书、对象 entries、排序转换、不支持字段报告。
- 内置资料：稳定 ID、玩家排除出 AI 角色、首次导入、清单一致性、不重复导入、不覆盖用户编辑、参考资料加载。
- 安卓 UI：创建世界和角色、导航、流式聊天与 Activity 重建、退后台保存中断文本、深色记忆表编辑与隔离。
- 进程重启：独立脚本对比强制停止前后持久化记录；测试密钥未以明文出现在 SharedPreferences。

## TDD 证据

业务模块先添加测试，确认缺失实现导致编译失败，再实现转绿。备份跨世界关联测试先得到运行时失败，再补语义校验；直接数组世界书测试先失败，再实现解析和排序转换。

重复设备测试时，累积世界让目标卡片落在屏幕外。测试改为滚动至目标后，完整测试通过。Lint 提醒补齐新旧 Android 备份规则，现已关闭系统自动备份，保留手动 ZIP 备份。

原始日志在本机 `.tools/`；提交摘要不含私有资料。测试摘要见 `validation/`。

## 复现

```powershell
./scripts/build.ps1 -Tasks ':core:test',':core:jacocoTestCoverageVerification',':app:assembleDebug',':app:lintDebug',':app:assembleDebugAndroidTest'
./scripts/test-device.ps1 -Serial emulator-5580 -AdbPath '<working-adb.exe>' -SkipBuild
python scripts/check-restart.py --adb '<working-adb.exe>' --serial emulator-5580
```

本机受限环境中 SDK 37 的 ADB 用户目录解析失败，设备验证使用已有兼容 ADB 连接独立官方模拟器；没有修改已有模拟器数据。

## 未验证边界

- 用户的真实 API、embedding 服务及模型实际上下文长度。
- Android 8.0 实体手机及厂商锁屏、后台、键盘差异；当前只跑过 API 35 模拟器。
- 自然长篇剧情的摘要质量和召回准确率；执行机制测试不能保证模型不产生错误记忆。
- 云同步服务、商店发布及第三方酒馆数据库插件私有格式未实现。

本项目没有 npm / pip 依赖清单，npm audit / pip audit 不适用。Gradle 依赖固定版本，未使用远程依赖审计服务。
